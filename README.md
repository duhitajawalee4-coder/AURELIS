# AURELIS — Multi-Page Website

AURELIS is a student digital-marketing project for architectural surfaces.

## Pages
- index.html — Home
- collections.html — Surface collections
- spaces.html — Space guides
- visualizer.html — Room visualizer + Surface Match
- compare.html — Surface comparison + calculator
- journal.html — SEO-friendly journal
- about.html — About AURELIS
- contact.html — Contact form demo

Open `index.html` to start. All pages share the same `styles.css`, `script.js`, and local images..
